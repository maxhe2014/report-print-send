# Stock Picking ZPL Label Print 模块测试指南

## 测试前准备

1. **确保模块已安装**
   - 登录 Odoo 后台
   - 进入应用模块 (Apps)
   - 搜索 "Stock Picking ZPL Label Print"
   - 如果已安装，进行下一步；如果未安装，点击安装

2. **升级模块**
   - 在应用模块中找到 "Stock Picking ZPL Label Print"
   - 点击 "升级" 按钮
   - 等待升级完成

## 功能测试

### 1. 用户打印机配置测试

1. **设置用户默认ZPL打印机**
   - 进入设置 > 用户与公司 > 用户
   - 编辑当前用户
   - 在 "偏好设置" 标签页下找到 "ZPL Label Printing" 部分
   - 选择默认的 ZPL 打印机
   - 可选：设置默认的 picking 标签模板
   - 保存设置

2. **设置标签模板特定打印机**
   - 在同一用户编辑页面
   - 找到 "Label Template Printers" 标签页
   - 点击 "添加一行"
   - 选择一个标签模板和对应的打印机
   - 保存设置

### 2. 标签打印测试

1. **从库存调拨单打印**
   - 进入库存 > 操作 > 调拨单
   - 打开一个调拨单
   - 点击 "打印 ZPL 标签" 按钮
   - 在弹出的向导中：
     - 确认默认标签模板是否正确
     - 确认默认打印机是否正确（应优先使用标签模板特定打印机）
     - 设置打印份数
     - 点击 "打印" 按钮
   - 验证标签是否成功打印

2. **从批次/序列号打印**
   - 进入库存 > 批次/序列号
   - 选择一个或多个批次
   - 点击 "打印 ZPL 标签" 按钮
   - 在弹出的向导中：
     - 选择一个适用于批次/序列号的标签模板
     - 确认默认打印机是否正确
     - 设置打印份数
     - 点击 "打印" 按钮
   - 验证标签是否成功打印

### 3. 优先级测试

1. **测试标签模板特定打印机优先级**
   - 为某个标签模板设置特定的打印机
   - 确保用户默认打印机不同
   - 打开打印向导并选择该标签模板
   - 验证系统使用的是标签模板特定打印机，而不是用户默认打印机

2. **测试用户默认打印机**
   - 确保没有为某个标签模板设置特定打印机
   - 打开打印向导并选择该标签模板
   - 验证系统使用的是用户默认打印机

## 故障排除

### 常见问题

1. **错误：UndefinedColumn: column res_users.zpl_picking_label_template_id does not exist**
   - **原因**：模块未正确升级，数据库字段未创建
   - **解决方法**：在应用模块中升级 "Stock Picking ZPL Label Print" 模块

2. **向导中没有可用打印机**
   - **原因**：用户未配置默认打印机，且未为标签模板设置特定打印机
   - **解决方法**：在用户设置中配置默认 ZPL 打印机

3. **标签打印失败**
   - **原因**：打印机未连接或 ZPL 模板错误
   - **解决方法**：检查打印机连接并确保标签模板有效

### 日志检查

如果遇到问题，可以查看 Odoo 日志文件获取详细错误信息：
- 日志文件通常位于 Odoo 服务器的日志目录
- 查找与 "stock_picking_zpl_label_print" 相关的错误信息
